# VineReach — Fase 1: Generador de carruseles de ventas B2B

Un generador automático de carruseles de LinkedIn para equipos comerciales de bodegas de Castilla y León.

## Qué hace

Introduces el tema, perfil del vendedor y beneficios de tu producto. La herramienta genera automáticamente un carrusel de 8 slides optimizado para ventas B2B, listo para publicar en LinkedIn.

## Cómo usarlo

1. Abre `index.html` en tu navegador
2. Rellena los campos del formulario:
   - Tema del carrusel
   - Perfil del vendedor (SDR / AE / VP Sales)
   - Nombre del producto
   - Público objetivo
   - 3 beneficios clave
3. Presiona "Generar Carrusel"
4. Navega los slides y copia el contenido

## Stack

- HTML, CSS, JavaScript
- Claude API (opcional para generación con IA)

## Contexto

Este es el **Fase 1 de VineReach** — un sistema completo de ventas AI para bodegas que consta de:
- **Fase 1**: Generador de carruseles (contenido)
- **Fase 2**: Agente de prospección (identifica clientes potenciales)
- **Fase 3**: Reporting automático (métricas semanales)

## Para qué sirve

Demostra cómo la IA puede automatizar la creación de contenido de ventas sin invertir horas en diseño o copywriting.
